💻 Exercícios com Laços de Repetição em PHP
Este repositório contém uma série de exercícios desenvolvidos em PHP, com foco na prática dos principais laços de repetição: while, do...while e for.

🧠 Objetivo
O principal objetivo desses exercícios é reforçar o entendimento e a aplicação de estruturas de repetição, que são fundamentais na lógica de programação. Cada exercício busca resolver problemas simples e práticos, utilizando diferentes tipos de loops conforme a necessidade.
